# Portfolio Project

This repository contains the source code for a personal portfolio web application. It is built using a modern React-based stack with a headless CMS approach for dynamic content management.

## Tech Stack

*   **Framework:** Next.js
*   **Styling:** Tailwind CSS
*   **CMS:** Payload
*   **Backend:** Supabase + PostgreSQL

## Architecture Overview

The application utilizes Next.js for the frontend client. Content is managed through Payload CMS. Payload CMS is configured to connect to a remote PostgreSQL database hosted on Supabase, acting as the primary data store.
